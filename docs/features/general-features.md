# 通用功能组

通用功能组包含适用于所有用户的功能，主要改善论坛的浏览体验和界面优化。

## 功能列表

### 1. 导航菜单管理

允许用户在吾爱破解论坛上自定义显示/隐藏导航菜单。

**功能特点**：

- 配置通过浏览器 storage 本地存储
- 支持实时切换显示/隐藏状态
- 提供重置为默认配置功能

**使用场景**：

- 简化界面，隐藏不常用的导航菜单
- 根据个人习惯定制界面布局
- 快速恢复默认设置

### 2. 深色主题支持

自动检测系统主题（深色/浅色模式）并应用相应的主题。

**功能特点**：

- 自动检测系统主题（深色/浅色模式）
- 实时响应系统主题变化
- 使用 CSS 变量实现主题切换

**技术实现**：

- 监听 `prefers-color-scheme` 媒体查询
- 动态切换 CSS 变量
- 平滑的主题过渡效果

### 3. 紧凑布局

优化了组件布局，减少页面滚动，提高空间利用率。

**优化内容**：

- 描述文字移至悬停提示
- 标签和开关在同一行显示
- 优化了所有间距

**效果**：

- 减少 30% 的垂直空间占用
- 提高信息密度
- 改善移动端浏览体验

### 4. 样式管理优化

每个组件管理自己的样式，符合组件化原则。

**样式管理策略**：

- Toggle 组件样式统一在 `src/styles/toggle.css` 中
- 全局 CSS 变量定义在 `src/entries/popup/index.html` 中
- 使用 `scoped` 避免样式污染

**优势**：

- 提高代码可维护性
- 避免样式冲突
- 便于主题定制

### 5. 组件分组

将功能开关按用途分为两组，提高代码可维护性。

**分组方案**：

- **通用功能组**（`GeneralFeaturesToggle.vue`）：楼层高亮、原生楼层、重贴检测
- **后台管理功能组**（`AdminFeaturesToggle.vue`）：头像查询、快捷回复、自动填充、全选、分表选择、默认时间、审核查询、勾选范围、灌水筛选

**效果**：

- 主组件代码量从 536 行减少到 349 行
- 逻辑更清晰，便于维护
- 提高组件复用性

## 配置说明

### 存储键

- `navigationEnabled` - 导航菜单管理开关
- `darkThemeEnabled` - 深色主题开关
- `compactLayoutEnabled` - 紧凑布局开关

### 默认状态

所有通用功能默认启用，用户可以根据需要关闭。

## 技术实现

### 组件结构

```
src/components/
├── GeneralFeaturesToggle.vue    # 通用功能组组件
└── 各个独立功能组件
```

### 样式管理

- 全局样式：`src/entries/popup/index.html`
- 组件样式：各自组件的 `<style scoped>` 部分
- 共享样式：`src/styles/toggle.css`

### 状态管理

- 使用 `browser.storage.local` 存储用户偏好
- 实时同步状态变化
- 支持批量操作

## 使用指南

### 启用/禁用功能

1. 打开扩展设置页面
2. 找到"通用功能"组
3. 点击对应功能的开关按钮
4. 状态立即生效，无需刷新页面

### 自定义配置

- **导航菜单**：可以单独控制每个菜单项的显示/隐藏
- **主题模式**：支持跟随系统或手动选择
- **布局密度**：可以在紧凑和标准布局间切换

### 重置设置

每个功能都提供重置按钮，可以一键恢复默认设置。

## 常见问题

### Q: 为什么我的主题没有自动切换？

A: 请检查系统主题设置是否正确，并确保浏览器支持 `prefers-color-scheme` 媒体查询。

### Q: 紧凑布局会影响功能使用吗？

A: 不会，紧凑布局只改变视觉呈现，所有功能都保持完整可用。

### Q: 如何恢复默认的导航菜单？

A: 在导航菜单设置中点击"重置为默认"按钮。

### Q: 样式管理优化有什么好处？

A: 避免样式冲突，提高代码可维护性，便于后续功能扩展。
