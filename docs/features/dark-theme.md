# 深色主题支持

## 功能概述

深色主题支持功能允许浏览器扩展自动检测并响应系统的深色/浅色主题设置，提供更好的用户体验和视觉舒适度。

## 核心特性

### 1. 自动主题检测

- **系统主题检测**：自动检测操作系统或浏览器的深色/浅色模式设置
- **实时响应**：当系统主题发生变化时，扩展界面自动切换主题
- **无配置要求**：用户无需手动设置，自动跟随系统偏好

### 2. 主题切换机制

- **CSS 变量实现**：使用 CSS 自定义属性（CSS Variables）实现主题切换
- **平滑过渡**：主题切换时有平滑的动画效果
- **一致性**：确保所有界面元素都正确应用主题样式

### 3. 视觉设计

- **深色主题**：深色背景、浅色文字，减少夜间使用时的眼睛疲劳
- **浅色主题**：浅色背景、深色文字，适合白天使用
- **对比度优化**：确保两种主题都有足够的对比度，符合可访问性标准

## 技术实现

### CSS 变量定义

主题相关的颜色变量定义在 `src/entries/popup/index.html` 中：

```css
:root {
  /* 浅色主题变量 */
  --background-color: #ffffff;
  --text-color: #333333;
  --border-color: #e0e0e0;
  --primary-color: #007bff;
  --secondary-color: #6c757d;
}

@media (prefers-color-scheme: dark) {
  :root {
    /* 深色主题变量 */
    --background-color: #1a1a1a;
    --text-color: #f0f0f0;
    --border-color: #444444;
    --primary-color: #0d6efd;
    --secondary-color: #adb5bd;
  }
}
```

### 组件样式应用

所有组件都使用 CSS 变量，而不是硬编码的颜色值：

```css
.component {
  background-color: var(--background-color);
  color: var(--text-color);
  border: 1px solid var(--border-color);
}
```

## 配置说明

### 功能开关

深色主题支持功能默认启用，用户无法手动关闭。这是为了确保扩展界面始终与系统主题保持一致。

### 存储配置

- **存储键**：无特定存储键（自动跟随系统设置）
- **配置类型**：只读，无法手动修改
- **同步范围**：仅本地生效

## 使用场景

### 1. 夜间使用

当用户在夜间使用电脑时，系统通常会自动切换到深色模式，扩展界面也会相应切换，减少屏幕亮度对眼睛的刺激。

### 2. 节能模式

某些设备在节能模式下会自动切换到深色主题，扩展界面也会跟随切换，帮助节省电量。

### 3. 个人偏好

用户可以根据个人视觉偏好设置系统主题，扩展界面会自动适配。

## 开发注意事项

### 1. 颜色使用规范

- 始终使用 CSS 变量，不要使用硬编码的颜色值
- 确保所有新组件都遵循主题变量规范
- 测试两种主题下的视觉效果

### 2. 测试要求

- 在深色和浅色主题下分别测试界面
- 验证主题切换时的平滑过渡效果
- 确保所有文本都有足够的对比度

### 3. 可访问性

- 深色主题下的对比度至少达到 4.5:1
- 浅色主题下的对比度至少达到 7:1
- 避免使用纯黑色背景，使用深灰色更舒适

## 故障排除

### 常见问题

1. **主题不切换**
   - 检查系统是否支持 `prefers-color-scheme` 媒体查询
   - 验证 CSS 变量是否正确定义
   - 确保浏览器缓存已清除

2. **颜色显示异常**
   - 检查组件是否使用了正确的 CSS 变量
   - 验证 CSS 变量值是否有效
   - 确保没有样式覆盖了主题变量

3. **过渡效果不流畅**
   - 检查是否在颜色属性上应用了 `transition`
   - 验证过渡时间和缓动函数设置
