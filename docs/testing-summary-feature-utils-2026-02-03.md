## 🔧 测试模式和最佳实践

### 1. 异步初始化处理

所有功能管理器都使用异步初始化模式，测试时需要等待初始化完成：

```typescript
const manager = createFeatureManager()

// 等待初始化完成
await vi.waitFor(() => {
```
